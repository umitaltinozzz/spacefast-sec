# Spacefast Security MCP — Terms of Use (review draft)

_Last reviewed: 12 November 2026. Review and approve this text before publishing as binding terms._

## Purpose and permitted use

Spacefast Security provides informational security analysis of dependency manifests, source code patterns, and allowed Spacefast deployments. You may use it only on projects, files, and systems that you own or have explicit authority to assess. Do not attempt to bypass the service's target restrictions or use it to compromise another party's systems.

## No guarantee of coverage

Vulnerability data and scans can be incomplete, stale, or inaccurate. A finding labelled `needs_validation` requires human verification. A report without confirmed vulnerabilities is not a guarantee that an application is secure. Review all outputs before taking production security decisions.

## No automatic remediation

The MCP's remediation functionality generates proposed changes; it does not automatically modify, build, or publish your code. If a separate tool can apply changes, review the proposed diff and the effect on your system before approving it.

## User responsibility

You are responsible for ensuring you have the right to submit project files, credentials, and URLs to remote services. Do not submit passwords, tokens, keys, or confidential/personal data unnecessarily. Test suggested fixes in a safe environment before deploying them.

## Service availability

The service may be interrupted, rate limited, changed, or discontinued. External vulnerability feeds may become unavailable.

## Open-source components and licenses

The software is distributed under the license stated in its repository. External vulnerability data and third-party sources retain their own terms and licenses.

## Liability and warranty

The service is provided on an **as-is** basis, without a promise of continuous availability or complete vulnerability detection, to the extent permitted by applicable law. Nothing here limits rights that cannot legally be excluded.

## Contact

For questions or security reports, open an issue at https://github.com/umitaltinozzz/spacefast-sec/issues.
